# Hotspot Collector Project Skills

This directory mirrors the `dsaj4/personal-skills` project layout:

```text
<skill-project>/
  skill/       Runnable skill body: SKILL.md, agents, scripts, references, assets.
  workspace/   Development notes, research, validation logs, and future revisions.
```

Use `skill/` when installing or loading a runnable skill. Use `workspace/` for notes and experiments that should not enter the active skill context.
