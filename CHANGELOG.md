# Changelog

All notable changes to this project will be documented in this file.

## 0.1.0 - 2026-05-28

- Added Bilibili subscription collection with optional explicit cookie support.
- Added Bilibili following discovery and followed-UP batch collection commands.
- Added WeChat RSS integration through a local WeWe RSS wrapper.
- Added X API v2 account, follower, follower-timeline, and recent-search skeletons.
- Added nine hotspot sources including Bilibili, Weibo, Zhihu, Douyin, Baidu, GitHub, Hacker News, Google News, and X.
- Added one-shot scheduler commands.
- Added Vitest tests, public fixtures, fixture validation, CI, license, contribution, and security docs.
